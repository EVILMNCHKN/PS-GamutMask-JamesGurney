# PS-GamutMask-JamesGurney

James Gurney’s Gamut Mask built in Photoshop 
By EVILMNCHKN

Pull from Git happily... or angrily

Ensure your Notes tab is open so you can read the tutorial note in PS (Also is the one below)

Use the Paths Tab for the Pen tool with the mask in the Group "Gamut Tool" under the Layers tab. This allows you to create custom Gamuts and reshape them however you like.

Use the pen tool in combination with Path Selection Tool (Hot Key A) and Direct Selection Tool (Hot Key A) (Shift+A toggles between the two)

Use the Colour Sampler Tool under Ink Dropper Tool (Hot Key I) to pick points on the colour wheel and then adjust your Gamut Mask to them. That way you colour pick and remember their locations. (Colour Sampler Tool icon is the ink dropper with the target symbol) (Click and hold on the ink Dropper tool in the toolbar if you have a hard time finding it)

If you are missing the Paths, Layer, or any other tabs you'd like, click on View at the very top of photoshop, and a list of tabs will appear for you to toggle on or off.

If you need to convert an anchor point to a straight anchor point and not a curved one when you add anchor points to your gamut mask, use the Anchor Point Conversion tool under Pen Tool
